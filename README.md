A single deadpan weather line for Wobbleford, a city that does not exist: nine millimetres of rain falling uphill by midday, and gusts strong enough to return lost umbrellas to their original owners. Delivered with the straight face of a TV meteorologist who has seen it all. A tiny Python program writes the line to `entry.txt` for make.fun's Deadpan Forecasts bounty.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
